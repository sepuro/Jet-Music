01 · Engineering & Architecture

Built with Media3, Jetpack Compose, and Modular Audio DSP

Jet Music is engineered in Kotlin as a multi-module Android application designed around predictable playback latency, clean visual hierarchy, and local-first reliability. Rather than bundling heavy web wrappers or bloated background frameworks, the codebase separates audio transport, digital signal processing, lyrics resolution, and Compose UI rendering into isolated Gradle modules so every layer remains lightweight and responsive.

Media3 / ExoPlayer Playback Engine

At the core of the :playback module, Jet Music runs a dedicated MediaSessionService backed by AndroidX Media3 and ExoPlayer. Network streams and local audio files flow through a custom ChunkingDataSource and OkHttp transport layer that minimizes start-up buffering, supports gapless track transitions, and maintains reliable lock-screen, Bluetooth, and Android Auto media controls. Playback progress state is isolated from root Compose hierarchies so timeline updates never force full-screen recompositions.

Dolby Atmos, Spatial Audio & USB Audio DSP

For listeners using studio headphones, wireless codecs, or external DAC hardware, Jet Music integrates dedicated :dsp-core, :audio-dsp, and :usbaudio modules. The engine exposes hardware-assisted Spatial Audio and Dolby Atmos profiles alongside customizable multi-band equalization. When an external USB audio interface is connected, audio routing can bypass unnecessary software resampling to preserve dynamic range and stereo separation.

Real-Time Synchronized Lyrics (LRC)

The :lyrics orchestration layer queries multiple open lyrics providers—prioritizing timestamped [mm:ss.xx] LRC sources such as LrcLib and KuGou before falling back to timed subtitle tracks and plain text only as a last resort. Starting in v2.2.1, Jet Music performs multi-stage query normalization to match remixes, live versions, and featured artist credits within an expanded duration tolerance, while purging unsynced cached entries from the local Room database so time-aligned lyrics stay accurate. Users can also adjust per-track millisecond offsets that persist locally across sessions.

Music Flow 1080p Visual Feed & Native Android TV

Music Flow provides an optional full-screen vertical discovery experience built directly on top of the shared MusicService queue without spawning duplicate ExoPlayer instances. Video surfaces render through hardware-accelerated TextureView layers with smooth alpha-blended transitions, selectable playback quality up to 1080p Full HD, and 50ms lyric synchronization. On living-room screens, Jetpack Compose adaptive layouts automatically scale into a clean, D-Pad-friendly Android TV interface with zero extra configuration.

02 · Deployment & Maintenance

Installation Guide & Automatic OTA Updates

Jet Music is distributed as a signed, standalone Android Package (APK) compiled in GitHub Actions directly from the public source repository. Before installing, review the minimum device requirements and follow the three steps below to set up the application cleanly.

Minimum OS
Android 8.0 Oreo (API Level 26) or newer
Supported ABIs
Universal (arm64-v8a & armeabi-v7a)
Current Release
v2.2.1 (versionCode 197)
  1. 1

    Download the Official Signed APK

    Tap Download APK at the top of this page or visit the GitHub Releases page to fetch the latest universal APK built from the main branch.

  2. 2

    Authorize Package Installation on Android

    Open the downloaded .apk file from your browser or Android Files app. If prompted by Android security settings, enable Install unknown apps for your browser or file manager, confirm the installation prompt, and wait a few seconds for package verification.

  3. 3

    Receive Seamless In-App OTA Updates

    Once installed, Jet Music includes a built-in over-the-air (OTA) updater that checks GitHub Releases for newer monotonic versionCode builds. When an update is available, the app downloads the APK securely, hands it off to Android's package installer via FileProvider, and upgrades in place without erasing your local playlists, Room history, or preferences.

All official release builds are signed using unified v1, v2, and v3 apksigner schemes and verified for SHA-256 certificate consistency in our CI pipeline. This guarantees that OTA updates install cleanly over previous versions and protects users against tampered third-party repackages.

03 · Frequently Asked Questions

Performance, Caching, Compatibility & Privacy

Answers to the most common technical questions about how Jet Music runs on modern and older Android hardware.

1. How does Jet Music deliver smooth 60–120Hz animations without UI stutter?

The Compose UI layer enables Strong Skipping Mode and stability configurations across domain and database models. Playback timers are read exclusively inside draw-phase callbacks rather than triggering parent layout recompositions, while album artwork color extraction runs off the main thread on downscaled 64×64 bitmaps using Dispatchers.Default.

2. How does background playback affect battery consumption?

Audio playback runs inside a standard Android Media3 foreground service using hardware-accelerated decoders, allowing the screen to stay off with minimal CPU wakeups. When Music Flow or background video playback is active and the user collapses the player into the MiniPlayer, the video TextureView surface is disposed immediately so GPU memory and video decoding do not drain battery in the background.

3. How does smart caching work for artwork, streams, and synced lyrics?

Coil 3 manages image loading with a 25% RAM memory cache and a 250 MB disk cache using hardware bitmaps to avoid decoding oversized thumbnails during fast scrolling. Metadata, play statistics, and lyrics are stored locally in a versioned Room SQLite database. Unsynced plain-text lyric entries are automatically purged when empty or outdated so synchronized LRC timestamps take priority.

4. Which Android devices, screen sizes, and peripherals are supported?

Jet Music supports Android 8.0 (API 26) through Android 16 across arm64-v8a and armeabi-v7a processors. Adaptive Compose layouts automatically adjust for compact phones, foldables, tablets, and Android TV screens with full D-Pad navigation, alongside Bluetooth audio devices and external USB-C DACs.

5. What user data is collected, and how does Jet Music protect privacy?

Listening history, playlists, custom equalizer profiles, and taste snapshots are stored locally on your device using Room and DataStore Preferences. Optional integrations—such as Last.fm scrobbling, Discord Rich Presence, or custom AI translation endpoints—remain disabled unless explicitly configured by the user. Website visitors can review our full cookie and AdSense disclosures in the Privacy Policy.

6. How can I verify that an APK download is authentic and safe?

Every release of Jet Music is compiled transparently from the public GitHub repository via automated GitHub Actions workflows and signed with a consistent release certificate. Always download builds directly from jetmusic.site or the official GitHub Releases page rather than third-party mirror sites.

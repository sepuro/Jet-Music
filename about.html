Project & Developer

About Jet Music

Jet Music is a minimalist, open-source Android music player crafted with Kotlin, Jetpack Compose, and Media3 (ExoPlayer) to deliver high-contrast typography, fluid transitions, and hardware-conscious audio playback.

Design Philosophy & Engineering

Rather than cluttering listening sessions with heavy web views or inconsistent UI widgets, Jet Music pairs a stark, Nothing-inspired visual system with a modular Gradle architecture. Core responsibilities—media session playback, Room persistence, DSP equalization, USB audio routing, and synchronized LRC lyrics resolution—are cleanly decoupled across independent modules so improvements can be tested and shipped rapidly.

Every release (currently v2.2.1) is compiled automatically via GitHub Actions, verified with unit test suites across database migrations and lyrics timing logic, and signed with v1, v2, and v3 APK signatures for safe in-place OTA updates.
